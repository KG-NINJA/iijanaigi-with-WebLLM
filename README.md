# Yomi Izanagi RPG - GitHub Pages files

Upload this folder's contents to GitHub Pages:

- `index.html`
- `assets/enemy-sheet.png`
- `assets/izanagi-frame.svg`
- `assets/yomi-background.png`

Do not upload `server.cjs`; GitHub Pages only needs static files.

If using a repository named `username.github.io`, place these files at the repository root.
If using a project page, place these files in the branch/folder configured for Pages.

## WebLLM enemy AI

Press `敵AI: 通常` in the game to download and enable the local WebLLM model.
WebGPU is required. Dialogue and tactics are generated in the browser; the
original deterministic enemy AI remains the fallback.
